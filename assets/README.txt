LOGO
====
Para usar o logo oficial do Empório das Bebidas:

1. Coloque o arquivo PNG aqui com o nome `logo.png`
2. No index.html, troque todas as referências de `assets/logo.svg` por `assets/logo.png`
   (ou apenas mantenha o SVG como fallback — ele já está estilizado na cara do empório).

O SVG atual é uma versão estilizada que segue a identidade visual:
medalhão dourado, fundo marinho, dois canecos de cerveja e tipografia Cinzel.
